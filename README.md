# BINGOゲーム用抽選機

1から75までの番号を重複なしで抽選する、GUI版とコンソール版の抽選機です。

## 起動方法

プロジェクトのフォルダーで、使用するバージョンを起動してください。

### GUI版

```powershell
python bingo_gui.py
```

### コンソール版

```powershell
python bingo.py
```

## BINGOの抽選ルール

番号は次の5グループに分かれています。各グループは15個です。

| 列 | 番号 |
| --- | --- |
| B | 1–15 |
| I | 16–30 |
| N | 31–45 |
| G | 46–60 |
| O | 61–75 |

抽選した番号は残りの番号から取り除かれるため、同じ回の中で重複しません。

## GUIの操作

1. `START`を押して最初の番号を抽選します。
2. 番号が切り替わる抽選演出のあと、当選番号が確定します。
3. 続けて抽選する場合は`NEXT`を押します。
4. 抽選済み番号はB・I・N・G・Oの列に表示され、75個すべて抽選すると終了します。

抽選中は黄色いボール枠と短い効果音、番号確定時は緑の枠と確定音で状態を示します。

## 必要な環境

- Python 3
- GUI版ではTkinter
- Windowsでは効果音に標準の`winsound`を使用します。利用できない環境ではシステムベルを使用します。
